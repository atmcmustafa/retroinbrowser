Fonts for generated images (Open Graph, icons). Satori needs static TTF files, so these are
static instances from the Google Fonts API, subset to Latin (ASCII, Latin-1, Latin Extended-A
and common punctuation):

- `Archivo-Expanded-ExtraBold.ttf`: Archivo, wdth 125, wght 800
- `Inter-Regular.ttf`, `Inter-SemiBold.ttf`: Inter, wght 400 and 600
